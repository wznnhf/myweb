# 拾题本地自习室

双击项目根目录的「启动拾题.command」，或在 `app` 中运行：

```sh
.venv/bin/python -m uvicorn server:app --host 127.0.0.1 --port 8765
```

## 学习打卡与界面

数学和 408 首页，以及错题本、每日回顾、每日一练、考点抽奖机首页，均显示 GitHub 风格的学习日历。默认查看最近 365 天，可切换自然年；按北京时间划分日期。

- 明确标记做题结果、复习状态或完成考点评分后记录；浏览、写笔记、收藏和自动排题不计入。
- 同一天同一板块的同一道题只计一次；科目首页汇总时，跨板块的同题也去重。题目和考点分别识别。
- 格子按 0、1～4、5～9、10～19、20 道及以上逐渐加深。支持点击、悬停和键盘方向键查看日期详情，手机上可横向滚动。
- 学习足迹反映实际做过的练习；修改结果、撤销评分或恢复旧备份不会抹去已产生的足迹。
- 自动补入旧记录中有明确作答或评分时间的记录，不依据笔记更新时间推测历史做题日期。

数学与 408 使用独立视觉主题。数学采用复古羊皮纸、棕黑墨迹、朱红批注和宋体标题，首页重排为演算手稿，试卷用开放式编目呈现；题目、笔记、答案、错题本、每日回顾、学习日历和弹窗都随科目切换。408 保留深黑荧绿主题和动态轨道。顶部导航固定；电脑、平板和手机分别调整布局，所有资源保存在本地，无需在线字体。

切页时保留当前内容，数据就绪后淡出并衔接新页面；阅读器按上一题／下一题方向滑入。导航选中下划线连续移动，目录错峰入场，滚动时渐次呈现，并为按钮、进度和弹窗加入短动效。响应系统「减少动态效果」设置，关闭动效后仍可正常使用；快速连续切页只展示最后一次选择。

## 408 每日一练

切换至「408 计算机」，进入首页的「每日一练」，点击「开始每日一练」。

- 使用 27 Relax 1000 题 7.29 勘误版，共 1576 题；四科题量为 411、373、417、375。
- 从点击开始当天起按北京时间逐日开放，每科通常每天 10 题；整轮 42 天，跨天不重复。
- 各科按章节题量比例分配，累计补足各章名额，章节内随机排列。题组生成后写入 SQLite，刷新或重启不重抽。
- 第 38 天 28 题，第 39～41 天各 20 题，第 42 天 8 题。漏练可从练习日历补做。
- 本轮全部题目开放后，可安排明天开始新一轮；旧轮次的作答和未完成题组保留。
- 已导入用户提供的《27relax1000题解析册·10月勘误版》，1576 题逐题核验。题图下方选择 A/B/C/D 自动保存，交卷前不返回对错、正确答案或解析；全组完成后点击交卷，统一判分并更新掌握状态。轮末不足 40 题时完成当日全部题目即可交卷。
- 5 道多空题逐空选择，部分完成也会保存，所有空正确才算答对。交卷前可修改，交卷后锁定；刷新、重启和跨天补做保留选择与交卷记录。
- 交卷后逐题显示你的选择、正确答案和十月版解析 PDF 原页。速对表与逐题解析的 3 处冲突采用逐题解析：操作系统文件管理第 7 题 C、计网数据链路层第 68 题 C、计网传输层第 44 题 A。校验报告位于 `output/relax-answers/import-report.json`。
- 交卷判分后，所有错题自动加入 408 的「每日一练错题」错题夹，并标记为未掌握；重复交卷不会重复收录。已有同名错题夹会继续使用，笔记和其他分类保留，全对时不创建空错题夹。成绩区可直接进入错题夹，收录的题目也会进入「每日回顾」候选池。
- 笔记和 408 错题夹继续共用。原有手动对错记录保留，需重新选择后才能以新流程交卷。

## 整站视觉与动态效果

数学首页使用原生 SVG 演算插画：曲线描绘、鹅毛笔与积分公式同步书写、推导和墨迹下划线依次浮现；背景保留低对比公式、纸纹与微尘，目录悬停时出现墨线。右上角「暂歇笔墨」可停止装饰动画，并呈现完整公式；切入后台暂停笔墨，尊重系统减少动态效果设置。数学页面不运行字符雨绘制循环。408 保留字符流、进度环和扫描线。学习日历置于首页底部；手机题图支持横向滑动与放大。主题入口为 static/parchment.js 和 static/parchment.css，仅作用于数学；云端 sites/shiti-cloud 是独立版本，不随本地前端修改自动同步。

## 408 记忆卡（考点抽奖机）

当前只使用用户提供的四份 CodeBrick PDF：数据结构 32 张、计算机组成原理 20 张、操作系统 43 张、计算机网络 45 张，共 140 张、26 章。原大纲卡已从练习和目录移除；旧评分保存在历史数据中，兼容旧备份，不转移成新卡的掌握状态。

- 从首页选科目、章节、到期／新卡／混合／整章模式，每组 10／20／40 张或最多 100 张。整章入口覆盖该章全部卡片，每组无重复。
- 核心挖空支持逐处揭示，亦可切换整卡回忆或阅读结论。揭示状态按本机保存，完整翻开状态与阅读位置由数据库保存。
- 答案保留原 PDF 的列表、表格、公式和加粗重点，理解说明折叠展示；可跳到保存于项目中的来源 PDF。考频为源资料标注。
- 评分后自动进入下一张；支持本组目录跳转、暂停续学、结束小结和撤销最近一次评分。空格展开、1～4 评分、左右方向键切卡，输入框和弹窗不触发学习快捷键。
- 正常复习沿用 FSRS；整章练习中的未到期卡作为提前练习，保留原调度。重复提交、刷新和并发进入不会重复评分。
- `data/knowledge/memory-cards.json` 是当前卡库；`sources/` 保存四份原 PDF 和版本指纹，`cloze-overrides.json` 保存额外审校的挖空词。原大纲卡的题面与答案已移除，`archive/` 仅保存旧记录标识，用于校验历史备份。
- `import_memory_cards.py` 从带结构标签的 PDF 重建结论与理解两个层次，处理嵌套 ActualText（兼容汉字、连字与等号），导入检查报告位于 `output/knowledge-reference/import-report.json`。

## 数据与备份

学习记录保存在 `data/study.sqlite3`。网页中的「备份与恢复」导出 v9 JSON，包含每日一练选项与交卷记录、连续复习队列、评分、学习打卡、每日一练整轮排期、结果和阅读位置。兼容 v1～v8，旧备份不会删除每日一练记录。同一轮按完整轮次恢复，其他轮次保留；日期重叠的不同轮次会拒绝合并。恢复前自动保存当前数据。

JSON 不包含题图和原 PDF。搬迁时还应保留 `data/relax-catalog.json`、`data/questions`、`data/sources`、`data/knowledge`，以及原有数学、408 试卷及其他题库资料。

## 重新导入与检查

```sh
.venv/bin/python import_relax.py '题册.pdf'
.venv/bin/python audit_relax.py
.venv/bin/python import_relax_answers.py '27relax1000题解析册_10月勘误版.pdf'
.venv/bin/python -m unittest discover -s tests -v
node --test tests/test_markdown.mjs
```

导入脚本仅针对这版题册的目录和排版，保留带 SHA-256 指纹的题册副本，生成 24 个章节容器和原书题号。不要用其他版式的 PDF 直接覆盖已有题库。

`output/relax-import` 包含逐章首尾题及跨页题预览、题号检查报告和像素检查报告。像素检查逐页确认题目裁切范围之间没有遗漏原书内容，补充 PDF 公式字形位置不准确时的文本检查。

测试使用临时数据库，浏览器验证使用独立的 `CUOTI_DATA_DIR`，不会写入正式学习记录。
