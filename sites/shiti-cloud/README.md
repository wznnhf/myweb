# 拾题 · 云端自习室

本网站从现有本地拾题迁移而来，保留数学试卷、408 真题与 Relax 章节、答案、笔记、错题夹、每日回顾、每日一练、学习日历和 CodeBrick 记忆卡。

## 使用

首次克隆后，在 `sites/shiti-cloud` 目录执行 `cp cloud/initial-study.example.json cloud/initial-study.json`，创建空白初始学习数据。个人学习记录、数据库、备份和本地托管配置不提交到公开仓库；已有本地 `initial-study.json` 时请保留原文件。

使用 .openai/hosting.json 对应的 Sites 私有网址，在每台设备登录网站所有者的 ChatGPT 账号。学习记录写入 D1，笔记图片和恢复前备份写入 R2。原本地网站的数据保持独立，后续学习请统一使用云端网址；可以通过页面的备份导入导出搬运记录。

## 数据与并发

初始记录保存在服务端 cloud/initial-study.json，只在空数据库首次访问时导入。已初始化的数据库不会被后续发布覆盖。每项学习记录独立存储；修改使用全局乐观锁和 D1 原子批处理，避免两个设备的更新互相覆盖。笔记保留原有 revision 校验和本机未保存草稿。重复评分具有幂等性。

FSRS-6 参数、学习步骤及原有 v8 备份格式保持一致。每日一练使用与 CPython 一致的 MT19937 字符串种子和洗牌，支持排期与本地备份精确互通。记录日期使用北京时间。

Sites 平台负责私有访问认证。本网站的学习数据为单一所有者空间，保持 owner-private 访问策略；如需多人独立使用，须先实现用户数据隔离。

## 检查

使用 starter 的构建命令。Drizzle 管理 D1 的两张表，迁移位于 drizzle。tests/integration.mjs 针对 127.0.0.1:8787 的独立预览数据库测试读写、并发冲突、错题夹、每日一练、回顾、考点幂等评分和撤销、备份恢复、资源及跨站写入限制。测试会修改预览数据库，不要改成生产网址运行。

源数据和本地测试输出不在 public。public 仅包含题库、题图、原 PDF、前端资源和原笔记图片。

## 题库资源构建

二进制题库为生成资源，不放入 Git。cloud/assets-manifest.json 绑定每份原始输入和生成输出的 SHA-256、大小与转换参数；scripts/prepare-study-assets.py 从原项目生成缺失文件，--verify 校验当前输出。发布前校验全部资源，再将生成资源打入部署归档。源仓库包含清单、生成脚本、前端与服务端代码；部署归档包含完整可运行资源。

## 云端二进制资源

为避开单个大归档的传输时限，构建后运行 node scripts/externalize-study-assets.mjs，把生成的二进制从部署包移除；这些文件由 R2 提供。scripts/migrate-study-assets.mjs 通过仅所有者可访问的 /api/admin/assets 分批导入，服务端严格校验清单中的大小和 SHA-256。脚本只从隐藏标准输入接收网站 URL 与临时服务令牌，不保存令牌。可以通过 status 自动跳过已上传内容，上传后核对全部资源数量。
